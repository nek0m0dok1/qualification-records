# 資格管理アプリ：データモデル

本書は、保存するデータの項目・型・関係を定義する。登録・検証・表示・保存のルールは `data-handling.md` を参照する。

英語の項目名・結果の保存値・保存パスは実装用の提案である。

## データの関係

| データ | 役割 |
|---|---|
| 資格情報 `qualifications` | 資格名・級または区分・固定タグ |
| 取得情報 `acquisitions` | 資格の取得年月・最新の更新年月 |
| 受験履歴 `examAttempts` | 受験日・結果 |

取得情報と受験履歴は、`qualificationId` で資格情報を参照する。

```text
資格情報
 ├─ 取得情報：0〜1件
 └─ 受験履歴：0〜複数件
```

- 資格情報は本人の記録内で共有する。他の利用者とは共有しない。
- 同じ資格に複数の受験履歴を関連付けられる。
- 「英検2級」と「英検準1級」は別の資格情報として扱う。
- 関連付けには名前ではなくIDを使用する。
- 資格名・級・タグの変更は、参照する取得情報・受験履歴の表示にも反映される。
- 取得情報があればあなたの資格として扱う。受験履歴は必須ではない。
- 取得情報は取得・更新それぞれの根拠となる合格履歴IDを任意に保持する。履歴なしの取得・更新も許可する。

## 資格情報

| 項目 | 型 | 条件・意味 |
|---|---|---|
| `id` | string | 必須。資格情報のID |
| `name` | string | 必須。資格名。空文字・空白のみは不可 |
| `gradeOrCategory` | string | 任意。級または区分 |
| `fixedTagIds` | string[] | 任意。固定タグのID。未選択は空配列 |
| `memo` | string | 任意。資格についてのメモ。未入力は空文字 |

固定タグは `language`、`it`、`business-finance`、`law-public`、`industry`、`health-welfare`、`education-childcare`、`life-culture`、`other` とする。表示名とIDを共通定義で分けて管理する。自由タグは初期版の必須範囲に含めない。

## 取得情報

初期版では、同じ資格IDに対する取得情報は1件とする。

| 項目 | 型 | 条件・意味 |
|---|---|---|
| `id` | string | 必須。資格IDと同じ値。資格ごとに一意 |
| `qualificationId` | string | 必須。本人の資格情報を参照する |
| `acquiredMonth` | string | 必須。取得年月。`YYYY-MM` |
| `acquiredAttemptId` | string | 任意。取得の根拠となる合格履歴ID |
| `renewal` | object | 任意。最新更新の年月 `month: YYYY-MM` と任意の根拠履歴ID `attemptId` |
| `previousRenewal` | object | 任意。取り消し時に1回だけ戻す直前の更新年月と任意の根拠履歴ID。`renewal` がある場合のみ |

- 取得年月と更新年月は別項目として保持する。
- 更新年月は資格そのものを更新した年月であり、記録を編集した日時ではない。
- 資格の更新で取得年月を上書きしない。
- 最新更新と直前更新を1件ずつ保持し、それより古い年月は保存しない。
- 受験履歴を登録しない更新では根拠履歴IDを省略する。

## 受験履歴

| 項目 | 型 | 条件・意味 |
|---|---|---|
| `id` | string | 必須。受験履歴のID |
| `qualificationId` | string | 必須。本人の資格情報を参照する |
| `examDate` | string | 必須。`YYYY-MM` または `YYYY-MM-DD` |
| `result` | string | 必須。以下の結果のいずれか |

| 保存値案 | 表示 |
|---|---|
| `passed` | 合格 |
| `failed` | 不合格 |
| `pending` | 結果待ち |

取得年月・更新年月は取得情報に保存する。受験日から自動転記しない。

## 日付の表現

- 年月・日付は時刻・タイムゾーンを持たない文字列とする。
- 取得年月・更新年月は `YYYY-MM` とし、日は含めない。
- 受験日は日が不明なら `YYYY-MM`、判明していれば `YYYY-MM-DD` とする。
- 不明な日を1日や月末日で補完しない。
- 入力・保存・JSON復元で扱う日付の年は1900年から2100年までとする（両端を含む）。この範囲外の年を含む既存記録・バックアップは検証で拒否されるため、移行方針は別途判断する。

## 保存パス

```text
users/{uid}
└─ datasets/{datasetId}
   ├─ qualifications/{qualificationId}
   ├─ acquisitions/{qualificationId}
   └─ examAttempts/{examAttemptId}
```

`uid` は認証された利用者のIDとする。

Firestoreの文書IDを論理的な `id` とする。資格文書本文には `id` を重ねて保存しない。JSONにはIDを明示する。取得文書IDは資格IDを兼ねる。利用者文書には `activeDatasetId` と単調増加する `revision` を保持する。データセットメタデータには状態と3種の記録件数を保持し、置換復元の切り替えと全件取得の整合性確認に使う。

固定タグ・メモ・受験履歴との関連は確定済み。JSON形式のバージョン1と置換復元は `data-handling.md` を参照する。
