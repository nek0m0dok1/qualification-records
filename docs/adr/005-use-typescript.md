## ADR-005：開発言語にTypeScriptを採用する

- 日付：2026-10-09
- 状態：採用

### 背景

資格・取得日・受験日・合否などのデータを、入力画面、保存処理、一覧、検索で扱う。開発者はTypeScriptの使用経験がある。

### 決定

アプリケーションの開発言語にTypeScriptを採用する。

### 比較した候補と理由

- JavaScript：型定義なしで実装を始められる。
- TypeScript：データの構造を明示し、項目名や値の型の不一致を開発中に検出しやすい。

既存の経験を活かし、データを扱う処理の保守性を高めるため、TypeScriptを採用する。

### 影響

- 資格と受験履歴のデータ構造を型として定義する。
- 型チェックを検証に含める。
- 型だけでは入力値やFirestoreから取得したデータの正しさを保証できないため、必要な実行時の検証も行う。
