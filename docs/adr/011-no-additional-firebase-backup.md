# ADR-011：Firebase上の正式データに追加バックアップを設けない

- 日付：2026-10-09
- 状態：採用
- ファイル名：011-no-additional-firebase-backup.md

## 背景

正式な記録はFirestoreに保存する。利用者自身が保管するJSONファイルによるバックアップ・復元は、ADR-010で採用している。

ユーザーは、Firebase上の正式データに対する追加バックアップを、初期版だけでなく今後の展望にも含めない方針としている。

## 決定

Firebase上の正式データに対し、アプリとして追加のバックアップを設けない。

以下は初期版の実装範囲および今後の展望に含めない。

- 利用者ごとのクラウドスナップショット
- 管理バックアップの導入・運用
- クラウド上の過去の状態から復旧する機能

ADR-010で決定したJSONファイルによる書き出し・復元は維持する。

## 比較した方針と理由

- Firestoreへの通常保存＋利用者によるJSONバックアップ
- 上記に加えて、Firebase上の追加バックアップを運用する

正式データの追加バックアップを製品の範囲に含めないというユーザーの方針に基づき、前者を採用する。

## 影響と制約

- Firestoreへの通常保存は、過去の状態を保持するバックアップではない。
- 端末を失った場合も、認証手段とFirestore上の記録が残っていれば、再ログインして記録を取得できる。
- 誤削除・誤編集をクラウド上の履歴から復元することは保証しない。
- JSONから戻せる範囲は、書き出し時点の記録とADR-010の復元仕様に依存する。
- クラウドバックアップによる復旧を、利用者向けの機能として案内しない。
