## ADR-001：プライバシー保護では利用者間のアクセス分離を重視する

- 日付：2026-10-09
- 状態：採用

### 背景

資格・取得日・合否を含む受験履歴を扱う、複数の利用者向けの公開アプリを開発する。管理者は開発者本人一人である。

当初はプライバシー保護のため、IndexedDBによるローカル完結を検討していた。しかし、ユーザーは、他の利用者に見られず適切に管理されるなら、クラウドへ情報を預けることを許容している。

### 決定

ローカル完結を必須条件としない。各利用者の資格・受験履歴に、他の利用者がアクセスできないことを重視する。

クラウド上のアクセス制御は、画面側の表示制限だけでなく、保存先側でも適用する。

### 比較した方針と理由

- ローカル完結：アプリから資格情報をサーバーへ送らない。
- クラウド保存を許容：認証とアクセス制御で利用者間の情報を保護する。

ユーザーが重視する保護の範囲に合わせ、後者を採用する。

### 影響

- クラウド保存と複数端末からの利用を選択肢に含められる。
- 運営者にも内容を読ませないための、利用者だけが復号できる暗号化は必須要件としない。
- 端末に残るデータの保護は、クラウド上のアクセス制御とは別に設計する。
