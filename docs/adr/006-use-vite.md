## ADR-006：開発・ビルドツールにViteを採用する

- 日付：2026-10-09
- 状態：採用

### 背景

Vue 3とTypeScriptで開発するため、開発用サーバーと公開用ファイルの生成機能が必要になる。開発者はViteの使用経験がある。

### 決定

開発用サーバーと公開用ビルドにViteを採用する。

### 比較した方針と理由

- Vite：Vue公式のプロジェクト作成ツールで使用され、開発者にも経験がある。
- 別のビルド環境：今回の要件では、追加の設定・学習負担に見合う必要性が確認できていない。

Vue 3との組み合わせと既存の経験を重視し、Viteを採用する。

### 影響

- 開発時はViteの開発サーバーを利用する。
- 公開時はビルド成果物をホスティング先へ配置する。
- ビルドとは別にTypeScriptの型チェックを実行する。
- Viteの採用だけでは、オフライン対応やPWA対応は実現しない。
