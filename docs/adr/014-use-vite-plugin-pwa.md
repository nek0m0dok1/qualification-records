# ADR-014：画面のオフライン対応にvite-plugin-pwaを採用する

- 日付：2026-10-09
- 状態：採用
- ファイル名：014-use-vite-plugin-pwa.md

## 背景

初期版では、取得済みの資格・受験履歴をオフラインで確認・検索できる必要がある。

Firestoreの永続キャッシュはデータを保存するが、画面を表示するためのファイルは別途保存する必要がある。制作期間は約1か月である。

## 決定

vite-plugin-pwaのgenerateSW方式を使用し、WorkboxによるService Workerをビルド時に生成する。

- オフライン表示に必要なHTML・CSS・JavaScript・画像などを事前に保存する。
- 資格・受験履歴はFirestoreの永続キャッシュに任せる。
- Firebaseの認証・DB通信は、Service Workerの追加キャッシュ対象にしない。
- 新版が利用可能になった場合は利用者に案内し、更新操作によって切り替える。入力中に強制的な再読み込みを行わない。
- ホーム画面への追加対応は初期版の必須範囲に含めない。

## 比較した候補と理由

- プラグインによる生成：Viteのビルド成果物に合わせて保存対象を生成できる。
- Service Workerの手書き：柔軟に制御できるが、保存対象や更新処理の管理が増える。

制作期間と保守負担を考慮し、生成方式を採用する。

## 影響と制約

- 初回のファイル取得とService Workerの準備には接続が必要になる。
- オフライン対応の準備が完了したことを確認してから、利用可能と案内する。
- 保存対象には、詳細画面などで後から読み込まれるファイルも含める。
- ブラウザーの保存データが削除された場合、再度オンラインで準備する必要がある。
- Firebase Hostingへの自動公開後も、利用者が新版へ切り替えるまで旧版が動作する場合がある。
- プラグインの導入だけでホーム画面への追加対応を完了したとは扱わない。

## 検証項目

- 準備完了後、通信を切って再起動・再読み込みしても一覧・詳細・検索を利用できる。
- 新版の公開後に更新案内が表示され、利用者の操作で切り替わる。
- 入力中に新版が公開されても、強制的に再読み込みされない。
- 資格・受験履歴の取得はFirestore SDK経由で行われる。
