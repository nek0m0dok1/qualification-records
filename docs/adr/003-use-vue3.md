## ADR-003：フロントエンドにVue 3を採用する

- 日付：2026-10-09
- 状態：採用

### 背景

資格情報の入力・一覧・詳細・検索画面を実装する。開発者はVue 3の使用経験があり、Reactにも多少の知識がある。

将来的には、ホーム画面からアプリのように起動できる使い方を希望している。

### 決定

フロントエンドのフレームワークにVue 3を採用する。開発言語はTypeScript、ビルドツールはViteとする。これらの採用理由はADR-005・006に記録する。

### 比較した候補と理由

- Vue 3：既存の経験を活かして開発できる。
- React：多少の知識はあるが、今回の要件で切り替える明確な理由がない。

開発者の経験を活かせるVue 3を採用する。

### 影響

- 画面をVueのコンポーネントとして実装する。
- Vue 3の採用だけではオフライン対応は実現しないため、別途仕組みを用意する。
- 将来のPWA対応は可能だが、今回の決定でストア配布やホーム画面への追加を実装範囲に含めない。
