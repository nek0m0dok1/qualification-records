# ADR-007：オフライン閲覧にFirestoreの永続キャッシュを採用する

- 日付：2026-10-09
- 状態：採用
- ファイル名：007-use-firestore-persistent-cache.md

## 背景

初期版では、学校など接続が不安定な場所でも資格情報を確認・検索できる必要がある。追加・編集などの変更操作はオンライン時に行う。

クラウド保存にはFirestoreを採用済みである。

## 決定

オフライン閲覧用の端末内保存に、Firestoreの永続キャッシュを採用する。IndexedDBを直接管理する独自の保存処理は実装しない。

- オンライン時に、本人の資格・受験履歴を取得する。
- オフラインでは、取得済みの記録を確認・検索する。
- 検索は端末に取得した記録を画面側で絞り込む。
- 永続保存は、利用者が「この端末に記録を保存する」を選んだ場合に有効にする。
- 永続保存を選ばない場合、再起動後のオフライン閲覧は保証しない。
- ログアウト時は、端末内の記録を削除する。
- 永続キャッシュは、利用者が記憶を選択した端末だけで有効にする。設定変更後は次の初期化で反映し、無効化時にログアウトとキャッシュ削除を行う。
- キャッシュ利用不能・複数タブによる削除失敗は明示し、削除済みとは表示しない。
- 変更はオンラインでサーバー確認を必要とするトランザクションとして保存し、オフラインでは受け付けない。
- ログイン・アプリ復帰・再接続・保存後にサーバーから再取得し、手動更新にも対応する。

## 比較した候補

- Firestoreの永続キャッシュ：取得済みデータの保存をSDKに任せられ、独自実装を減らせる。
- IndexedDBを直接管理：保存・更新を細かく制御できるが、Firestoreとのデータ受け渡しを実装する必要がある。

対応範囲と制作期間を考慮し、Firestoreの永続キャッシュを採用する。

## 影響と制約

- キャッシュはバックアップとして扱わない。
- 未取得の記録は、オフラインで確認・検索できない。
- キャッシュの削除・整理によって記録が失われる場合があるため、全記録のオフライン閲覧を無条件には保証しない。
- アプリの画面をオフラインで開く仕組みは別途必要になる。
- キャッシュ削除の際は、Firestoreの終了や複数タブの扱いを含めて設計する。
- アカウント切り替え時に、前の利用者の記録を表示しないようにする。

## 検証項目

- オンラインで取得後、通信を切って再起動しても一覧・詳細・検索が使える。
- 対応する記録件数の範囲で、必要なデータがキャッシュに揃う。
- ログアウト後、前の利用者の記録を表示せず、キャッシュ削除の完了を確認する。
- オフラインでは変更操作が無効になり、再接続時に変更が送信されない。
- 永続保存を選ばない場合や、保存を利用できない環境で適切に案内する。
