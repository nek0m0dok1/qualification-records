# 資格管理アプリ　PRD

ねこもどき

# Overview

履歴書等で資格取得年月日を求められるが、細かく覚えてないし、合格証書引っ張り出すのも面倒。所持している資格の情報を一発で得られるアプリ

# Goal

* 資格情報の一覧を簡単に確認  
* ひな形に沿ってサッと記録できる  
* 大量にデータが存在する場合のための検索機能  
* 合否にかかわらず受験履歴を記録する  
* 固定タグを使用してあなたの資格を分類・検索する（複数選択はAND条件）
* 資格の詳細情報が必要になったら簡単に確認できる
* 初回だけメールで本人確認し、その後はメールアドレスとパスワードでログインする
* JSONバックアップ・復元を行う
* 事前取得した記録をオフラインで閲覧・検索する

# Non-Goal

* 「試験日まであと○日！」のような、資格取得の促進や奨励  
* 頻繁な確認  
* ランキング的なもの
* オフラインでの記録追加・編集・削除
* 自由タグ（必須機能完成後に再検討）
* 審査スライドの作成（利用者が作成する）

# Target User

* 学校で資格をポツポツと取るが、取得年月日を書けと言われても覚えてない学生  
* 資格取得が趣味の人（大量の資格を管理したい）  
* 専門性があるかつ学業・仕事に必要な資格を持っている/取る人  
* 履歴書を書く人（どんな場面でも）

# Core Feature

* 資格の基本情報と取得年月日等の保存、表示、検索

# User Story

* 次年度受験の高校２年生。総合型選抜のアピールポイントのために資格取得を頑張りたい。受験時に簡単に資格を参照するため、記録を残しておきたい。  
* 資格取得が趣味の会社員。スキマ時間に勉強している。資格コレクションを増やすことが好き。合格証書が膨大になってきたので、もっと簡単に自分の資格を眺められるものがほしい。  
* 就活中の新卒生。一社目の履歴書を書くときに、自分が何の資格をいつ取ったか曖昧で、資格を書き並べるだけなのに無駄に時間がかかった。次回以降の企業に提出する時にまた時間がかかりそうで面倒。

# Feature Flow

**記録時**

1. 資格情報入力欄に情報を入力  
2. 記録ボタンを押す

**確認時**

1. 一覧画面を表示  
2. 目的のものを検索する  
3. 情報確認
